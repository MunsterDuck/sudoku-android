# Sudoku 1.3.1

Release date: 2026-11-14
Tag: `1.3.1`
Version code: `1003001`

## Improved

- **Fast-mode highlighting.** Arming a digit now highlights every matching
  cell immediately, before the board is tapped. Matching digits in notes are
  highlighted as well.
- **Notes layout.** Notes are shown as a hand-written 3×3 mini-grid inside the
  cell. Each candidate keeps its standard position from 1 in the top-left to 9
  in the bottom-right, is centred in its mini-cell and is easier to read.
- **Cell selection.** The selected cell uses a light hand-drawn background wash
  instead of an outline frame. Note highlighting marks only the matching note
  digit.

## Notes

- The saved game and history format is unchanged; data from 1.3.0 loads as is.
- No rule changes.
- Store screenshots were refreshed for phone, 7-inch and 10-inch devices.
- This release is prepared for both Google Play and F-Droid from the same
  source tag.
